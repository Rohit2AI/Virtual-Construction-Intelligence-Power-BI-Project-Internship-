# 🏗️ Virtual Construction Intelligence (Power BI Project)

## 📌 Project Overview
This project focuses on strategizing, modeling, and executing a complete Business Intelligence solution for the construction industry using Microsoft Power BI over a 6-week structured lifecycle.

---

## 🗓️ 6-Week Execution Roadmap

| Week | Phase / Focus Area | Status | Key Deliverables | Primary Artifacts |
| :--- | :--- | :---: | :--- | :--- |
| **Week 1** | Strategic Planning & Market Analysis | 🟢 Completed | Strategic plan, KPI framework, market analysis, 3 use-case scenarios | `Strategic_Plan_Document.docx` |
| **Week 2** | Data Architecture & ETL Pipelines | ⏳ In Progress | Data extraction pipeline, cleaning scripts, data dictionary | Data cleansing scripts & raw schemas |
| **Week 3** | Data Modeling & DAX Formulas | ⚪ Pending | Star schema relational model, custom DAX measures (CPI, SPI, LTIFR) | Data model schema & DAX documentation |
| **Week 4** | Cost & Budget Dashboard Design | ⚪ Pending | Executive budget dashboard, waterfall cost variance visuals | Interactive financial report |
| **Week 5** | Safety & Supply Chain Analytics | ⚪ Pending | Site safety heatmaps, OTIF vendor metrics, delay analytics | Operational dashboards |
| **Week 6** | Deployment & Final Presentation | ⚪ Pending | Power BI Service deployment, RLS configuration, final report | `.pbix` dashboard file & summary PDF |
